# DDS Plenary Open Calls

Plenary open calls bring the DDS tracks together to share progress, surface cross-track questions, and discuss decisions that affect the wider Community Group.

## September 3, 2026

The group agreed to start simply: provide a shared GitHub gathering place for open standards, open-source tools, evaluation criteria, and real-world use cases; invite early contributors to present their work; and defer a formal taxonomy until participation reveals what structure is useful.
